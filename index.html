Version 1.4.2 · 9.4 MB · Android 12 or newer

How to install

  1. Tap Download for Android.
  2. Open the downloaded file (notification or Downloads).
  3. If Android blocks it, tap Settings and allow installs from your browser, then go back.
  4. Tap Install. If Play Protect warns about an unknown app, choose Install anyway.

Updating

Download again from this page and install over the old app. Your songs and folders stay.
